# 执行计划

1. 阅读后端错误处理、日志和运行部署规范，并定位 `.env` 中运行时代理变量的精确格式。
2. 修改流式普通异常分支，保留经过脱敏的最终错误。
3. 在既有市场分析器测试中加入该异常路径回归。
4. 设置 `USE_PROXY=false`，并清空本机 `.env` 中的 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY` 及其小写变量；不触碰密钥、模型渠道字段、`NO_PROXY`、代理地址字段或 Docker 构建代理。
5. 执行 `python -m py_compile src/analyzer.py` 与相关 pytest。
6. 以既有 Docker 启动方式重建 `stock-server`，核验容器内模型服务直连与一次单任务分析。

## 风险与检查点

- `.env` 变更只在重建容器后生效；重建前保留当前运行证据。
- 取消代理会影响所有应用运行时的外部访问；模型服务已实测可直连，其他外部数据源仍需在重建后通过定向功能验证。
- 不记录或输出完整环境变量值、请求授权头或模型响应。
