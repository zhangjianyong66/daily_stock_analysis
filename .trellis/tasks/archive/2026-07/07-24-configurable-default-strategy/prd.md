# 支持配置默认分析策略

## 目标

让单用户部署可以选择一个已有分析策略作为服务端默认值，替代只能依赖写死的内置默认策略。用户既能在设置页管理默认值，也能在首页策略菜单中一键把当前策略设为默认；所有未明确指定策略的新个股分析使用同一解析结果。

## 背景与已确认事实

- 当前单次分析已经支持通过 `skills` 指定策略；未传字段时，后端在 `src/agent/factory.py:256` 从 `AGENT_SKILLS` 或内置策略元数据解析默认策略。
- 当前 `/api/v1/agent/skills` 在 `api/v1/endpoints/agent.py:137` 始终按策略元数据返回主默认策略，没有反映服务端配置。
- 首页策略选择在 `apps/dsa-web/src/pages/HomePage.tsx:431` 将非空选项直接作为单次请求发送；默认项本身不能保存。
- Web 系统设置通过现有配置服务持久化到服务端 `.env`，具备校验、配置版本冲突和运行时重载能力。
- `AnalysisResult.strategy_execution` 已是报告实际执行策略的唯一事实源；历史报告不得用当前默认值回填或改写。
- 当前没有多用户配置域，本需求只提供一个部署级默认值。

## 需求

### R1：单一服务端默认策略

- 新增一个可选、单值的默认分析策略配置，值为当前可调用策略的稳定 skill ID。
- 配置持久化到现有服务端系统配置，服务重启、浏览器缓存清理或换设备后仍然有效。
- 第一版不支持保存多策略组合作为默认值。

### R2：统一优先级与生效范围

- 个股分析策略优先级固定为：单次请求明确选择 > 已保存默认策略 > `AGENT_SKILLS` > 内置元数据默认策略。
- 已保存默认策略适用于所有未明确指定策略的新个股分析，包括首页分析、批量/定时分析和 Agent 问股。
- 已保存默认策略作为固定默认值时，不应再被多 Agent 的自动行情路由替换。
- 大盘复盘继续使用独立的市场复盘策略，不读取本配置。
- 修改默认值只影响修改后创建的任务；已排队、执行中任务和历史报告保持原策略快照。

### R3：设置页管理

- Agent 设置分类提供默认策略下拉框，候选项来自运行时可调用策略列表，包含内置及已加载的自定义策略。
- 下拉框提供“跟随系统默认”，用于清除保存的覆盖值并恢复 `AGENT_SKILLS` / 内置默认解析。
- 保存沿用现有系统配置的校验、版本冲突、运行时重载和认证边界。

### R4：首页快捷设置

- 首页策略菜单中，每个可用策略提供“设为默认”操作；当前默认策略显示明确的“默认”标记。
- 普通选择只影响本次分析，不自动修改服务端默认值。
- 页面首次加载时视觉上选中当前有效默认策略，但在用户未操作策略选择时不得把它伪装为单次明确请求。
- 设置成功后立即刷新当前默认标记，并给出成功反馈；保存失败时保留原默认值并给出可理解的错误提示。
- 首页提供“跟随系统默认”恢复入口，清除保存的覆盖值。

### R5：失效配置与可解释回退

- Web 保存非空值时，服务端必须验证该 ID 当前可调用；未知、禁用或不可调用策略不得保存。
- 若 `.env` 手工修改、策略目录变化或升级导致已保存默认值失效，运行时按优先级回退到 `AGENT_SKILLS`，再回退到内置默认策略，不能阻断分析。
- 策略列表接口返回有效默认值、是否存在保存覆盖、默认来源及失效提示，供首页和设置页一致展示。
- 新报告继续记录最终实际执行策略及正确来源；历史报告保持生成时快照。

### R6：兼容性与文档

- 保留现有 `skills` / legacy `strategies` 请求字段与 `/agent/strategies` 兼容接口。
- 未配置新默认值的部署保持现有 `AGENT_SKILLS` 和内置默认行为。
- 新增配置项时同步更新 `.env.example`、相关配置说明和 `docs/CHANGELOG.md`。
- 用户可见首页与设置页变化需要在 PR 中提供截图证据，临时截图不得提交到仓库。

## 验收标准

- [ ] AC1：保存任一当前可调用策略后，重启或重载配置仍能从策略列表接口读到相同的有效默认值和保存来源。
- [ ] AC2：未传 `skills` 的首页分析、定时/批量分析和 Agent 问股均使用保存默认；明确传入其他策略时只覆盖本次任务。
- [ ] AC3：保存默认、`AGENT_SKILLS` 与内置默认同时存在时，执行结果严格遵循 R2 优先级；未保存覆盖时保持旧部署行为。
- [ ] AC4：首页首次加载显示有效默认但不发送伪造的显式 `skills`；用户手动选择其他策略时发送显式值。
- [ ] AC5：首页可以一键设为默认和恢复“跟随系统默认”，成功与失败均有反馈，默认标记不会在失败时误更新。
- [ ] AC6：设置页使用运行时策略列表作为单选候选，并通过现有保存流程完成校验、冲突处理和运行时重载。
- [ ] AC7：无效保存请求被拒绝；运行时发现历史保存值失效时降级继续分析，并向 Web 返回失效提示。
- [ ] AC8：修改默认值不改变已创建任务或历史报告的 `strategy_execution`；新报告保存正确的 `source`、`requested`、`effective` 和回退状态。
- [ ] AC9：大盘复盘行为和策略不受新配置影响。
- [ ] AC10：后端定向测试、前端定向测试、前端 lint/build、Python 语法检查均通过，文档与配置示例已同步。

## 非目标

- 不新增多用户、账号级策略偏好或权限模型。
- 不支持把多策略组合保存为默认值。
- 不修改策略内容、策略评分规则、回测算法或大盘复盘策略。
- 不重写现有 `AGENT_SKILLS` 多策略配置和自动行情路由的一般能力；只有保存了单一默认覆盖时才固定该默认策略。
