# 首页策略场景与 K 线形态推荐

## Goal

让用户在发起个股分析前快速理解每种策略适合的行情场景，并在个股报告中看到本次标的的日线 K 线形态、证据状态和匹配的后续分析策略，降低策略选择成本。

## Background

- 首页已有策略选择菜单，当前选择器保持单策略选择；未明确选择时沿用服务端默认策略，明确选择优先于部署默认值。
- 仓库已有 15 种内置策略的使用场景指南，工作区中 `docs/strategy-selection-guide.md` 和 `docs/CHANGELOG.md` 是用户现有未提交改动，必须保留并复用。
- 底层 `Skill` 已有 `category`、`market_regimes` 等元数据，但 `/api/v1/agent/skills` 目前只返回 `id`、显示名和描述，没有结构化场景标签。
- Agent 工具 `analyze_pattern` 已能扫描最近日线并返回形态名称、类型、强度、位置、说明和摘要，但结果尚未接入分析报告详情或历史重建链路。
- 分析结果已有模型生成的 `pattern_analysis` 文本字段；本需求新增的是独立、结构化、可持久化的形态报告数据，不替换旧字段。
- 历史报告必须读取分析当时保存的形态和推荐快照，不能用当前策略配置反推历史结果。

## Requirements

### 策略场景标签

- R1：首页策略菜单为每个内置策略展示最多 2～3 个短场景标签，并保留现有完整描述；标签允许换行，不得破坏移动端布局。
- R2：策略场景标签以策略定义为唯一语义来源。内置 YAML 增加结构化 `usage_scenarios`；自定义策略可选提供该字段，未提供时继续使用现有 `description` 作为兼容说明，不得阻塞加载。
- R3：策略接口向前端返回 `usage_scenarios`，兼容旧客户端忽略新增字段；系统文案支持中文、英文、韩文，缺失翻译时回退中文。

### 形态报告与推荐

- R4：所有个股分析执行一次最近 60 个交易日的日线形态识别，包括首页单只分析、批量分析和异步任务；大盘复盘不执行个股形态识别。
- R5：报告增加结构化形态报告，至少包含 schema 版本、状态、周期、窗口、数据源/时效、当前价格、识别到的形态列表和摘要。每个形态保留名称、类型、强度、发生位置和说明。
- R6：使用固定、可测试的规则完成形态到策略映射，每次最多展示 1～3 个当前可调用策略及推荐理由；推荐结果只作说明和后续选择入口，不自动触发第二次分析。
- R7：默认映射如下：
  - 放量突破 20 日高点、大阳线 → 放量突破、默认多头趋势。
  - 一阳夹三阴、缩量回踩 → 一阳夹三阴、缩量回踩。
  - 早晨之星、看涨吞没、双底、锤子线 → 底部放量、均线金叉。
  - 箱体震荡 → 箱体震荡；十字星只提示等待确认。
  - 黄昏之星、看跌吞没、流星线、上吊线、大阴线 → 情绪周期，仅作过热/风险判断，不给进攻性买入建议。
  - 倒锤子线或无法确认方向 → 不推荐，显示证据不足。
- R8：报告推荐可同时展示 1～3 个候选，但首页继续保持单策略选择；每个候选单独提供“选择此策略”入口，点击只替换当前选择，不自动提交分析。
- R9：形态数据获取或识别失败时主分析继续完成；报告明确显示数据不足、暂不可用或证据不足，并且不生成推荐。大盘复盘保持现有流程。

### 报告出口与兼容

- R10：结构化形态和推荐快照进入内存结果、原始持久化 JSON、同步/异步 API、历史 API 和 Web 报告；旧报告缺失该字段时正常展示。
- R11：Web 报告在策略点位之后展示形态摘要，详细形态列表和推荐理由可折叠展开；Markdown 报告和通知增加简洁摘要，不输出冗长原始数据。
- R12：新增报告文案支持中文、英文、韩文，翻译缺失时回退中文；历史报告使用保存时的形态与推荐名称、理由和状态。
- R13：新增逻辑不得改变现有策略选择、默认策略解析、任务入队冻结、报告策略快照和主分析 fail-open 契约。

## Acceptance Criteria

- [ ] 首页每个内置策略显示 2～3 个可扫描场景标签；自定义策略无标签时仍可用现有描述正常展示；桌面端和移动端均无溢出或布局跳动。
- [ ] 新生成个股报告的 API 详情包含结构化日线形态报告；识别成功时包含形态列表和摘要，失败或数据不足时包含明确状态。
- [ ] 报告推荐最多 3 个策略，均来自分析当时可调用策略集合，并包含匹配形态和推荐理由；看跌形态不会产生进攻性买入推荐。
- [ ] Web 报告摘要默认可见，详情可展开；点击任一推荐只改变首页单选策略，不自动创建分析任务。
- [ ] Markdown、通知和历史报告能读取同一持久化快照；旧报告无该字段时不报错、不伪造形态。
- [ ] 中文、英文、韩文报告文案均有测试覆盖，缺失翻译回退中文。
- [ ] 通过受影响的 Python 定向测试、前端测试、`py_compile`、Web lint 和 Web build。

## Out of Scope

- 不自动依据推荐策略发起第二次分析。
- 不扩展首页为多策略选择器。
- 不覆盖周线、分钟线或多周期形态融合。
- 不把形态或策略推荐表述为确定收益或机械买卖信号。
